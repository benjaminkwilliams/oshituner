# Triage labels

| Skill role and GitHub label | Meaning |
| --- | --- |
| `needs-triage` | Maintainer review is pending. |
| `needs-info` | More information is needed from the reporter. |
| `ready-for-agent` | An agent can implement the fully specified issue. |
| `ready-for-human` | A human needs to implement the issue. |
| `wontfix` | The maintainers have decided against doing the work. |
